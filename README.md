# 40 ans du Groupe Arverne

Page web statique pour les **40 ans du Groupe Arverne** (Scouts et Guides de France) —
**3 & 4 octobre 2026, Aubière**.

## Contenu

- `index.html` — la page complète, autonome (HTML / CSS / JS, aucune dépendance à installer)
- `assets/` — logo SGDF
- `img/` — photos optimisées pour le web (carrousel « Souvenirs »)

## Configuration

Les deux liens sont dans la balise `<script>` en bas de `index.html` :

```js
const LIENS = {
  formulaire : "https://tally.so/r/LZgegp",        // inscription (Tally)
  comites    : "https://comeety.krlx.fr/e/bmuemtu" // commissions (Comeety)
};
```
